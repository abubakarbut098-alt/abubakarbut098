This project is a modern and fully responsive **Gym Website** created using **Generative AI tools**. The purpose of this project is to design a professional fitness website using prompt engineering and AI-based website generators.

Create a modern, highly professional, and fully responsive "Gym Website" with a premium dark theme (black, charcoal grey, and neon accents such as red or electric blue). The design should feel futuristic, clean, and visually engaging, suitable for a high-end fitness brand.
